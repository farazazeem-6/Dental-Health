# Dental Health

A single-page landing site for a dental clinic — hero, smile gallery, implant/services
overview, contact, and footer, built as a fast static React app.

## Tech Stack

- [React 19](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- [Vite](https://vite.dev/) for dev server and build
- [Panda CSS](https://panda-css.com/) for styling — no other CSS framework or UI library

## Getting Started

```bash
pnpm install
pnpm dev       # start the dev server
pnpm build     # type-check and build for production
pnpm lint      # run eslint
```

`panda codegen` runs automatically before `dev`/`build` via the `predev`/`prebuild` scripts, so
the generated `styled-system/` output always matches `panda.config.ts`.

## Project Structure

```
src/
  App.tsx          composition root — wires the page sections together
  types/           shared TypeScript interfaces (Service, ContactDetail, FooterColumn, ...)
  constants/       all copy, prices, hours, links, and image URLs, typed against src/types
  hooks/           standalone hooks (useIsMobile, useMaskPositions, useStaggeredReveal, ...)
  ui/              small reusable primitives (Button, ArrowIcon, MaskedCard)
  view/            page sections (Navbar, HeroSection, GallerySection, ContactSection, ...)
panda.config.ts     design tokens (colors, fonts) and the shared button recipe
styled-system/       generated by Panda CSS — do not edit by hand
```

## Styling

All colors are design tokens declared once in [panda.config.ts](panda.config.ts) under
`theme.extend.tokens.colors` — components reference tokens like `'brand.black'` or
`'surface.glass'` rather than hardcoding hex or rgba values. See [CLAUDE.md](CLAUDE.md) for the
full set of conventions this project follows.
